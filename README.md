# Unmute1AI

**Making every signal accessible to all.**

We build accessibility-first AI for human communication, assistive experiences, and accountable agent actions. Our work connects accessible interfaces with model orchestration, explicit authorization, and recovery tooling.

## How the projects fit together

- **Communication:** OmniSign, SIGNAL-AV, and domain interfaces explore ways to express intent through sign, gesture, text, and speech.
- **Assistive applications:** Myelin provides a workspace for API and interface development.
- **Reasoning:** AnnealMesh generates and ranks candidate responses; SAGE integration explores edge cognition.
- **Authority and evidence:** Sentinel is the authorization design; Glass Box publishes scoped evaluation evidence.
- **Recovery:** Phoenyx Ignis implements a policy-guided recovery environment.

These are distinct repositories at different stages. The portfolio is not yet a single integrated, deployed product.

## For partners and contributors
