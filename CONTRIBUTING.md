# Contributing to Unmute1AI

Thank you for helping make every signal accessible to all.

## Choose a project

Use the [portfolio directory](README.md#explore-the-work) to find the repository closest to your contribution. This repository holds the portfolio; implementation changes belong in the relevant project.

## Useful contributions

- Accessibility feedback from people using screen readers, keyboards, captions, magnification, or alternative input.
- Deaf and hard-of-hearing user research and sign-language evaluation.
- Neurodivergent interface feedback and sensory-accessibility improvements.
- Reproducible bug reports, setup fixes, and documentation corrections.
- Scoped evaluation of privacy, edge behavior, and authorization boundaries.

## Report a bug

Include the project and commit or release, device/browser/runtime, steps to reproduce, expected behavior, and actual behavior. Provide a small synthetic example when possible. Explain the accessibility impact directly.

For security reports, follow the affected repository's security guidance. Keep credentials, private recordings, and personal or patient data out of public reports.

## Propose a change

Explain the problem, what changes for users, and how you checked the result. Keep changes focused, preserve upstream attribution, and distinguish implemented behavior from future plans. Include keyboard and assistive-technology considerations when changing interfaces.

Benchmark claims should identify the version, environment, dataset or scenario, method, and limits. A model judgment is not a formal proof or a permission grant.

## Licensing

Follow the license and contribution terms of the target repository. Public visibility alone does not establish reuse permission, and this portfolio does not replace any project's license.
