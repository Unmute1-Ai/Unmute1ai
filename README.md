# Unmute1AI

**Accessibility-first AI infrastructure for communication, security, and edge intelligence.**

Unmute1AI builds systems that make multimodal communication more accessible while keeping consequential AI actions behind explicit, auditable authority boundaries.

## Core product tracks

- **OmniSign** — accessible ASL / gesture / multimodal communication
- **SIGNAL** — accessible intent and communication layer
- **U1 Sentinel / Glass Box** — model-independent execution authority and reproducible evidence
- **AnnealMesh** — reasoning verification
- **AEGIS-Q** — NVIDIA-edge embodied security for wearables and robotics
- **Phoenyx Ignis** — governed recovery
- **Myelin** — typed platform/API infrastructure
- **EMS Guardian / Clinical Sign / Telehealth** — accessible domain interfaces

## Engineering principles

1. Accessibility first.
2. Raw sensitive media stays local by default.
3. Model capability does not equal authority.
4. Unverified provenance fails closed.
5. Consequential effects require explicit, scoped authorization.
6. Public claims should point to reproducible evidence.
